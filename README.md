# 작은 회복 · 웹

1·3·5분 호흡 리셋과 명상 모드. 안드로이드 앱 「작은 회복」을 브라우저로 옮긴 판입니다. 아이폰에서는 Safari로 열고 **공유 → 홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

- 소리 12가지를 모두 기기에서 실시간으로 합성합니다(AudioWorklet, `synth.js`). 음원 파일이 없어서 라이선스 걱정이 없고, 같은 구간이 반복되지 않습니다.
  - 물소리·빗방울·파도 거품: van den Doel(2005)의 공기방울 모델
  - 모닥불·바람: A. Farnell, *Designing Sound*의 층 구성
- **호흡 파도**는 들이쉬기 4초, 내쉬기 6초인 호흡 원과 박자가 맞습니다.
- 기록은 남기지 않습니다. 소리·볼륨·가이드·명상 길이·종소리 설정만 이 브라우저(localStorage)에 저장하며, 어디로도 보내지 않습니다.
- 한 번 열면 오프라인에서도 열립니다(service worker).

## 명상 모드

- **화면을 켠 채로 듣습니다.** iOS는 화면이 꺼지면 웹 페이지의 실시간 오디오(Web Audio)를 멈춥니다. 그래서 웹판은 화면을 꺼도 이어지는 재생을 약속하지 않습니다. 화면이 꺼진 채 듣고 싶다면 안드로이드 앱이나, 나중에 만들 아이폰 앱을 쓰면 됩니다.
- 명상하는 동안에는 화면이 저절로 꺼지지 않습니다(Screen Wake Lock). 이 기능이 없는 브라우저에서는 그렇다고 안내합니다.
- **어둡게**를 누르면 화면 전체가 검게 바뀌고, 남은 시간만 희미하게 보입니다. 같은 자리가 계속 켜져 있지 않도록 1분마다 위치가 조금씩 바뀌고, 화면을 누르면 돌아옵니다.
- 시작과 끝의 싱잉볼 종소리는 켰을 때만 울립니다(기본 꺼짐).
- 명상 시간과 마무리(마지막 30초 페이드, 끝 종소리)는 오디오 스레드가 직접 셉니다.
- 화면이 꺼지거나 통화 때문에 소리가 멈추면 '잠시 멈춤'으로 바뀌고, 한 번 누르면 이어집니다.

## 개발

```bash
node test/synth.test.js
```

테스트는 12가지 소리를 48kHz로 합성해서 확인합니다.
- 음량, 최대 레벨, 무음 구간이 없는지, 같은 시드에서 같은 소리가 나는지
- 스테레오 폭
- 호흡 파도의 박자
- 명상 모드의 페이드 → 종소리 → 끝, 그리고 멈춤
- 합성 속도

로컬에서 보려면 정적 서버로 엽니다. AudioWorklet은 `file://`에서 동작하지 않습니다.

```bash
python -m http.server 4317
```

파일을 바꾸면 `sw.js`의 `VERSION`을 올려야, 이미 설치한 휴대폰도 새 버전을 받습니다.
